# Provenance

Created by Ben Schneider — https://github.com/Ben-Scr

The interval and set algorithms, domain tests and example are new independent implementations.
No private repository implementation or third-party algorithm source is included. The project has
no runtime package dependencies; build and test dependencies retain their respective licenses.

Build, test and package-audit infrastructure is adapted from the public
[BenScr.Resilience](https://github.com/Ben-Scr/BenScr.Resilience/tree/0a388abf85c47ab1c8712afa2f638d010b1b555a)
repository at commit `0a388abf85c47ab1c8712afa2f638d010b1b555a`, under the same author license.

The original custom `LICENSE.txt` is copied byte-for-byte, including its UTF-8 encoding and CRLF
line endings. SHA-256: `f6600e285e17c48188a65745d7595807e1755c72201e8eef201a9174fca18573`.

The unchanged common icon is `branding/BenScr_Icon_Master.png`, embedded as `icon.png`: 1254 x 1254,
RGBA, 795819 bytes. SHA-256: `a5dcabceb766e13c1840a95130ee98a458e12e3713fd9b07f3ceae75a1f5b993`.
No resized or modified image is shipped. The same byte-verified shared asset is used across the
library family; publication verification also checks the actual gallery rendering.

The exact GitHub target returned 404 before repository creation; the NuGet ID was also checked
before implementation. Build metadata and Portable PDBs record the exact source commit.
